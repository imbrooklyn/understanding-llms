## Human-reference dataset attribution and modifications

Source: LMSYS / Zheng and colleagues, [MT-Bench human judgments](https://huggingface.co/datasets/lmsys/mt_bench_human_judgments), revision `f7d2896d2cc5d80f8b55c2bbc722613555233c25`, human split. License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode.en), supplied as-is without warranties under that license. This is not an endorsement by the original authors.

The pinned Parquet SHA-256 is `4877bc46a40929f4082c3c79593700fb897b1d6c7f4c473032694a01322f5769`. `harvest_human.py` preserves source order, takes distinct question IDs from 100 upward, limits combined first-turn text length to 1800 Unicode characters, and keeps the first four qualifying pairs. It drops second turns, preserves first-turn text and human preference metadata, and records original row positions. The extraction rule predates local Judge execution. The original full Parquet file is not redistributed. Brief bilingual textbook descriptions are paraphrases; the retained fixed English pairs are the licensed source text.

The human votes concern the original pairs only. Newly generated self-comparison answers have no new independent human labels. Agreement 0/4 on this convenience slice is not the paper's full result or a population estimate. The separately consented travel labels do not replace or erase this adverse finding.

## Reproduction boundaries

The candidate order is fixed in the shared contracts and raw requests. No core algorithm uses random sampling; optional model seed 47 is recorded but does not promise bit-identical future runtime output. Hand examples use exact integers/fractions; reported logical seconds round to six decimal places. Model timings are actual recorded durations, not resource estimates. Fictional retention days are arithmetic units, not elapsed multi-day jobs. Both languages share corpus, algorithms, labels and figure sources.
