# Part VI fixed evidence

As of / last verified: 2026-09-13. Original fixtures, numeric expectations and recorded outputs: CC BY-SA 4.0. No third-party dataset or real user account is included.

| File | Origin and purpose |
| --- | --- |
| `sft-v1.json` | Assigned vocabulary, dialogue, probabilities and invalid format mutations; no real tokenizer probabilities |
| `preferences-v1.json` | Assigned preference pairs, scope/evidence metadata, rubric, audit outcomes and reward-gaming counterexample |
| `reasoning-v1.json` | Complete authored candidate pool, amount grammar, answer/process labels and three verifier acceptance vectors |
| `budget-v1.json` | Four questions, every candidate, three fixed orders, charged call quota, fixture lexer and independently enumerated expected costs/quality |
| `low-rank-v1.json` | Assigned integer matrices, dimensions, scale and a uniform quantization illustration (not NF4) |
| `expected.json` | Independent hand-derived integer results and symbolic decimal expectations, written before implementation |
| `mechanism-run-v1.json` | Actual standard-library CPU replay with source hashes, all 60 order/cap/method rows, complete calls, token accounting and controller time |
| `notebook-execution.json` | Actual fresh-kernel execution, code/artifact hashes and input provenance |
| `content-contract.json` | Bilingual content/figure/exercise anchors used by repeatable static and browser checks |
| `dependency-licenses.json` | Installed distribution versions, declared licenses and exact license-file hashes; dependencies are not redistributed here |
| `validation-manifest.json` | Actual build/browser/CPU results with source, log and local screenshot hashes; records which final captures supersede earlier ones |

Decimals use natural logarithms and Python binary64; chapter display usually rounds to six decimals. Integer matrix products and cost counts are exact. Candidate A/B/C order is local to each question. Repeats are explicitly scheduled rather than random model samples, so there is no random seed or model revision for controller replay. Fixture tokens use the declared lexer and must not be compared directly with model/API tokens. Replay milliseconds cover only controller, parser, lexer and verifier work.

Two independent arithmetic paths check the low-rank result: separate base/increment multiplication and multiplication after merging. Numeric tests also change inputs/caps, reverse KL, expose verifier failures and charge rejected candidates. Expected results are not generated by the implementation being tested.

Actual Mini GPT generations are in the continuing `data/knowledge-assistant/ka1-format-*-v1.json` assets, with their existing tokenizer, checkpoints, seeds, dependencies and adjudication. They are distinct from authored Chapter 37 answers. Preserve previous versions and unfavorable cases. The corresponding [decision report](../../docs/ka1-adaptation-report.md) records rejected options and unchanged semantic quality.
