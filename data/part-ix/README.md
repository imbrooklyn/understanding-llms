## Reproduction and limitations

Use [the CPU instructions](../../code/part-ix/README.md). Matching hashes establishes which bytes were used. It does not guarantee identical random output; default extraction makes no neural calls. Monotonic timestamps are seconds within one process run and cannot be compared as calendar timestamps. Durations are actual smoke-run observations affected by process startup, local scheduling and injected delays. Do not present them as model inference latency or capacity measurements.

The gate contains five independently authored cases in each of two languages. Keep its ten presentations separate from the original nine-query lexical task, six attack proposals, twenty permission rows and four-task injected layer comparison. The service synonym miss is retained outside the small release fixture. Feedback does not silently relabel or enlarge the frozen fixture. The reviewed case is explicitly separate even though it rechecks an existing policy boundary.

Runtime diagnostics omit question, credential, principal and answer. Full published traces are an intentionally separate synthetic reproduction bundle. Job/cache/feedback state is bounded and in memory; diagnostic and SQLite persistence depend on the selected state directory. This is not a complete production erasure implementation. See the Data Card for retention and human obligations.
