词汇表会随正式章节一起更新。术语第一次出现时会附上英文；同一个词用于模型、训练、运行或整个系统时，如果含义不同，也会分别说明。

| 中文 | English | 含义与区别 |
| --- | --- | --- |
| 训练 | training | 根据训练数据估计或优化模型参数，例如统计次数、学习权重。 |
| 模型运行 | inference | 用固定的参数执行模型计算，与 reasoning 说的不是一件事。 |
| 解题推理 | reasoning | 为解题安排中间计算或搜索步骤，与 inference 含义不同。 |
| 上下文 | context | 模型处理当前请求时能用到的信息，不等同于参数、长期记忆或 Agent 的状态。 |
