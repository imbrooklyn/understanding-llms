这是一部面向开发者的 Web-first 双语开放教材。核心理解路径不要求 AI、机器学习或 NLP 背景；实践路径会从必要的 Python、数学和工程基础开始。

## 你将建立什么

- 从 Text、Token、ID、Embedding、Transformer、Logits 到 Sampling，追踪一个 Token 的完整旅程。
- 区分 Training、inference 和 reasoning，并定位参数、上下文、外部知识与系统状态。
- 从 N-gram、RNN 和 Attention 逐步推导 Transformer 与现代 LLM。
- 把 Prompt、RAG、Tool、MCP、Skill、Workflow 和 Agent 放进同一张可靠系统地图。
- 通过 Mini GPT 与 Personal Knowledge Assistant 将机制落实为可验证的工程成果。
