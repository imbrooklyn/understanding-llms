# Chapter 21 figure sources

`training-curve.json` supplies localized labels for a static SVG rendered directly from `data/mini-gpt/training-run.json`. All 13 measured points and the selection rule are also visible in the chapter table. The axes use updates and nats per valid target, with line style and marker shape distinguishing splits in both themes.

`generation-decisions.json` is an original bilingual diagram of the recorded final-model aligned-red continuation. Probabilities are raw model probabilities, not the renormalized sampling probabilities.
