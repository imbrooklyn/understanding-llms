## Mechanism choices to validate locally

The exact response-cache key includes principal scope, question, date, topic, language and immutable release identity. Semantic similarity is illustrated with authored vectors and a false match; semantic caching is disabled. Default answer production is source extraction, so neural model/tokenizer/seed/precision fields are explicitly inapplicable; lexical tokenization and arithmetic are still versioned. The source Skill executes from reviewed bytes. An older-date candidate deliberately causes a current-date regression without corrupting the retained source fixture.

Trace publication contains only synthetic requests. Ordinary runtime diagnostics omit credentials and question text; the local reproduction bundle intentionally stores synthetic inputs separately. Feedback accepts bounded categories and does not collect arbitrary free text. Each of these is a project design choice to test, not a conclusion supposedly proved by a citation.
