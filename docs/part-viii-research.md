## Research decisions

The stable chapters teach guarded transitions, exact approvals, causal attribution and trust boundaries. Current endpoint fields and model tags belong in part-viii-online.md. No API pricing, leaderboard ranking or broad legal recommendation is required. OSTEP supplies a problem-driven writing method only; no copied prose or technical claim uses it as an LLM source.

The initial plan required independent consented travel labels. One real reader subsequently supplied pass/fail/pass/fail for the four fixed meanings and expressly consented to anonymous calibration use. The separate label record contains no identity or private author prompt. The public human slice adds transfer evidence; neither is relabeled to improve agreement. Preserve raw model failures, malformed output and unfinished responses. Source version checks and a small local attack suite are bounded evidence, not proof of security or production fitness.
