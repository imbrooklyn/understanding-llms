## Claims resolved through local evidence

The KA-1 frozen six bilingual cases already supply new/old lodging amounts, fictional status, an ungranted approval condition and unknown information. A failure on that prompt is not evidence that retrieval failed to supply the fact. Conversely, the prompt's fictional status is not a live order query. The post-run provenance note is retained with the original contract, not silently folded into a rewritten freeze.

A conservative terminal-period repair is justified only for full integer amount answers under an amount-output contract. It cannot repair the historical answer `750.` into `600`. Comparing the original raw response and the repaired displayed response against unchanged strict and semantic criteria isolates formatting. Any apparent improvement in literal matching must be reported separately from robust semantic case passes. This is a local diagnostic inference from the actual retained outputs; no paper is cited as proof of its effect on KA-1.

The chapter-37 candidate pool and call charges are author-assigned. Running a controller over that pool measures software behavior and local replay time; it does not measure a model generating those candidates. The actual KA-1 extension supplies the required same-evaluation-set runtime adaptation comparison. An unchanged gate can legitimately reject both configurations.

## Implementation and license boundaries

Core scalar exercises use Python's standard library. Actual MG-2 generation reuses the local, original CC BY-SA 4.0 model/data bundle and Apache-2.0 code, with its pinned CPU PyTorch dependency set. The practical record must include installed versions and hashes at execution. No Transformers, TRL, PEFT, bitsandbytes, external tokenizer, external checkpoint or proprietary prompt transfer is required. Their APIs are not promised as a tested recipe.

The optional real-PEFT planning checklist requires the exact base/tokenizer revision and license, training-data rights, target modules, rank/scaling, quantizer/storage/compute types, supported hardware, seeds and paired regression tests before training. An adapter's own license does not erase its base or data conditions. No external model's license is inferred from the words “open” or “distilled.” Links are attribution and technical evidence; none of the original paper figures, datasets or long passages is redistributed.
