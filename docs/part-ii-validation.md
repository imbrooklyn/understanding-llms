## Editorial review and repairs

Two review passes were completed in addition to automated checks. The technical pass traced each number back to its input/rule or actual record, checked first-use notation, denominators, axes and units, distinguished supplied values from measured results and cited paper findings, and checked prerequisites and chapter boundaries. It confirmed that retrieval, classification and language prediction use different evaluation objects; a fixed-window model can use combinations inside its window but cannot recover a clue outside it.

The reading pass read all seven complete Chinese files independently, then checked the English technical baselines again for semantic equivalence. Revisions improved local transitions and referents, explained an affine layer before relying on it, expanded the classifier's 1,218 and NNLM's 193 parameter counts layer by layer, added concrete local-rate calculations in both languages, clarified the recorded target versus a factually correct answer, and preserved the difference between a project milestone and a saved model checkpoint. Formula sets, source sets, exercise/answer numbering, figure meanings and required practice order were checked across languages. This was editorial reading, not a claim that test counts prove teaching quality.
