## Shared argument and evidence

Start with two unanswered questions from CH-04: how to process many numerical rows, and how an error changes a parameter. Then apply the resulting tools to imperfect text, establish cheap observable lexical baselines, and expose the distinction between learned representation and remembered context. All textbook values identify their status: authored inputs, independently derived arithmetic, actually measured runs, or research findings. No hand-assigned vector is described as trained Word2Vec. No diagnostic collection is described as a representative benchmark.

## Primer placement and scope

Complete CH-05's core first. Primer-PY then teaches notebook cells/kernel/order, files and paths, values and variable assignment, strings, indexed lists, keyed dictionaries, conditionals, loops, functions, errors, packages, NumPy arrays and PyTorch tensors, shapes, dtype/device, and reading a traceback. Each tool appears in the actual counting/shape practice that needs it. Include static inputs, expected results, exercises and visible solutions; notebook markdown is English implementation documentation. A clean CPU environment is the declared tested path; browser notebooks are an alternative only where actually verified. No HTTP primer work is included.

Run the parameterized character N-gram notebook after the primer, using ab/ab/ac and the original candidate order, BOS/EOS, six settings and LCG32 trace. Then complete the NumPy exercise, fixed logits and training notebooks. Saved notebook outputs supplement the chapters; no chapter's core explanation depends on execution.
