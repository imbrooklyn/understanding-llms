# Part VIII implementation snapshot

`as_of: 2026-09-14`; `last_verified: 2026-09-14`. Stable explanations are in Chapters 47–53. This optional implementation snapshot is not a publication announcement.

The core implementation uses Python 3.12.10, standard-library SQLite/subprocess/hashlib, and jsonschema 4.25.1. The fresh tested environment was installed from `code/part-vii/requirements-tested.txt`; portable direct requirements are reused by `code/part-viii/requirements.txt`. `data/part-viii/dependency-inventory.json` records installed distribution versions, supplier license/project metadata and the requirements digest. Exact versions do not supply wheel hashes, signed build provenance or vulnerability clearance.

The Agent Skills specification was read at https://agentskills.io/specification and its client implementation guide on the verification date. It is a live specification with no invented numeric release. The local package's `metadata.version: 1.0.0` identifies our package only. The host implements explicit discovery, activation, reference reading, a helper subprocess and a returned report. It does not install a general automatic Skill client. Experimental `allowed-tools` is deliberately not used as a security control.

MCP was verified against the official 2026-07-28 specification and security/authorization documentation. The existing KA-3 stdio server remains read-only; Part VIII hashes and adversarially tests copied implementation bytes without expanding that server's permissions. A2A is reference-only, positioned using the official specification's 1.0 examples. No A2A dependency is installed.

Optional actual model probes used an already installed `qwen3:1.7b` through local Ollama 0.34.0. The pinned manifest digest is `458ce03a21878025d072b8740d0e0e3b34abec3585fdadb0b5ab92d1e85dfb61`. `model-provenance.json` retains the manifest and five actual blob size/digest checks. The registry quantization is GGUF Q4_K_M; its observed runtime parameter-count description is not used to redefine the upstream model's name. Upstream Apache-2.0 was verified separately; conversion/build provenance remains unverified. No weights or runtime binaries are redistributed.

Both model runners use `/api/generate`, `stream: false`, `think: false`, fixed seed 47, temperature 0, four CPU threads and `num_gpu: 0`. The first uses context 2048 and at most 48 output tokens; human pair comparisons use context 4096, bounded 24-token verdicts, and a separate 160-token limit for exploratory new answers. Raw requests, responses, durations, stop reasons and `/api/ps` observations are retained. Every recorded loaded-model check reports zero VRAM. No pricing or throughput generalization is made from these runs. Core checks consume the saved raw records and require no model account or service.

`run_model_probes.py` and `run_human_calibration.py` are optional refresh commands for this exact local installation. Re-running them changes experimental evidence; do not overwrite unfavorable records during routine validation. A new model requires a new versioned experiment and provenance review. The present Judge is rejected for automatic release despite agreeing on the four consented domain labels.

The optional OS probe uses macOS 26.5.2 `sandbox-exec` and temporary fictional files plus a loopback listener. Its profile blocks network, protects one designated secret directory and restricts writes. General runtime reads remain possible. `sandbox-run.json` is actual evidence on this OS; the initial process-start failure is retained separately. No portable sandbox, escape-resistance result, real authentication provider or remote side-effect service is claimed.
