Editorial baseline: 2026-09-14. Scope: CH-40–46 and Primer-HTTP, English first and then equivalent Mainland Chinese prose. All sixteen language pages remain drafts without release dates. No commit, publication, deployment, PDF or page redesign is authorized.

## Starting state and dependency audit

The workspace contains separate book and main-site Git repositories; both were clean at the initial audit. No applicable AGENTS.md or Sites hosting manifest was found. The current source publishes CH-01–39 and Primer-PY, superseding the older Part I-only publication history. Those files and their publication state must be preserved. The fourteen target chapters and two HTTP primer files contain only placeholders. Placeholder instructions to remove draft flags do not apply.

Historical validation is not evidence of this increment's execution.

KA-0 is implemented in code/knowledge-assistant/baselines.py: five immutable cards, nine query pairs, explicit tokenization and candidate order, Keyword/Count/TF-IDF scores and failures. KA-1 has frozen cases, two actual CPU checkpoints, 144 attempts, adjudication and a rejection decision. Part VI's format adaptation preserves that rejection. There is no accepted general-purpose bilingual generator. This increment must not imply one exists. It will expose a generator boundary, run deterministic extractive composition locally and analyze explicitly authored generator responses separately from real model measurements. No new pretrained-model quality result is assumed.

Existing heading numbering, bilingual anchors, KaTeX, semantic lane figures, code-copy suppression and draft filtering already serve this part. New infrastructure is limited to part-specific behavior/content/browser checks, notebook entry points and enabling the existing figure transform for Primer-HTTP without adding chapter numbers to it. The sole missing bridge is Primer-HTTP, completed before CH-42 practice; no upstream chapter rewrite is needed.

Before drafting technical claims, inspect primary sources for JSON/JSON Schema, a selected vendor's official structured-output and tool boundary, formal current MCP and version/deprecation notes, HTTP semantics and streaming, BM25, dense passage retrieval, reciprocal rank fusion, reranking, original RAG and citation/layered evaluation. ## Final implementation choices

The primary paired intervention is eligibility filtering before top-one selection, with global BM25 statistics and identical sibling expansion in both conditions. Rewrite, parent expansion and compression are separate probes. Retrieval retains both the authored three-dimensional map and the previously learned four-dimensional NNLM representation; the reranker is an explicit scope rule. These choices expose the mechanisms without relabeling them as pretrained neural experiments.

The output adapter uses JSON Schema Draft 2020-12 and a typed Python record. The local MCP implementation pins the formally verified 2026-07-28 revision and covers discovery/list/read through actual stdio, rather than implementing a legacy initialization session. The HTTP Primer adds one original figure under ch-42. The completed increment has eight shared figures and two executable notebooks. The final validation record distinguishes actual new executions from the unchanged, previously rejected KA-1 model results.
