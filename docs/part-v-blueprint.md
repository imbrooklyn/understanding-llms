## Chapter argument contracts

### Chapter 22 — A lifecycle, with independent labels

Question: why does MG-2's familiar red completion fail to justify calling it a general assistant? Baseline: its 13875 parameters, 24 training records and failed explicit update probe. Read a vendor-neutral authored model card, asking separately about breadth of reuse, language scale, training stage, interface and tested reasoning behavior. Reconstruct corpus → pretraining → base snapshot → optional post-training → engine/server/application. Contrast a chat wrapper around unchanged base weights with changed weights behind an unchanged interface. Explain foundation, LLM, base, instruct, chat and reasoning labels without a universal parameter cutoff. Example: two cards with identical parameter counts and different provenance. Figure: state transitions and the evidence each transition adds. Exercises diagnose missing card fields and unsupported lifecycle claims. Sources: foundation-model report, model-card paper, instruction-training research and reasoning-model technical report. Handoff: the source and treatment of the data.

### Chapter 23 — Preserve provenance through transformations

Question: what reaches training after a downloadable document has passed through a pipeline? Start with original fictional records; declare acquisition basis separately from crawler preferences, contract terms and redistribution permission. Trace parse → filter → exact deduplication → synthetic contact redaction → mixture → contamination audit. One filter removes boilerplate; a digit-heavy filter mistakenly removes the 750 update. Restore the substantive record under a versioned revised rule. Show denominators after filtering, sampling with replacement, whole-record split and near-duplicate limits. Deliver separate Data Cards referencing the existing Mini GPT corpus and KA-0 document bundle, plus a small pipeline extension whose processed output does not silently replace either baseline. Figure: retained/rejected branches with record counts and causes. Exercises cover a counterfactual filter, mixture arithmetic and insufficient permission evidence. Sources: data-card/datasheet research, T5/C4 methods, deduplication study, RFC 9309 and official licenses. Handoff: tokens after processing become a resource budget.

### Chapter 24 — Compare budgets before extrapolating

Question: with the same training budget, should parameters or observed tokens grow? Derive the dense approximation C≈6ND from units and a declared forward/backward multiplier, using three budget-equivalent rows. Explain repeated exposures versus unique text and multiplication/addition FLOP conventions. A synthetic loss curve introduces log axes and a fitted power law; every plotted point is an assigned example, not a new scaling experiment. Discuss Kaplan and Hoffmann in their respective settings; do not import their fitted coefficients as a universal recipe. Compare equal training compute but different assumed lifetime generation volumes. Figure: paired resource factors with fixed product and the omitted attention term. Exercises change one constraint, identify an invalid extrapolation and calculate lifecycle cost. Sources: both original scaling papers and their methods/appendices. Handoff: component choices change cost and behavior even at similar scale.

### Chapter 25 — Three local changes inside one block

Question: what changes when a config replaces learned positions, LayerNorm and ReLU FFN? Recall Chapter 17's residual width. Work one two-coordinate rotation, one RMS calculation and one gated FFN, then place each on a single pre-norm block. Introduce angles through quarter turns before sine/cosine notation; rotate queries/keys without declaring value rotation. RMSNorm does not subtract a mean; an input offset is a counterexample. SwiGLU multiplies two projections elementwise and projects back; compare 3CF with 2CF parameter terms under explicit bias assumptions. Figure: Q/K position branch, per-row norm and two FFN branches rejoining the residual. Deliver a simplified teaching config, not an alleged framework schema. Exercises map fields, track a shape and challenge a long-context guarantee. Sources: RoFormer, RMSNorm, GLU Variants papers. Handoff: fewer KV heads and selective parameter use address other budgets.

### Chapter 26 — A map along three resource axes

Question: which resource is scarce: retained history, pairwise attention work or resident/active parameters? Compare MHA/MQA/GQA with eight query heads; compute stored K/V values per position. Trace a top-2-of-4 MoE with shared parameters to distinguish total and active counts; active FLOPs do not imply that inactive weights disappear from memory. Locate sparse attention masks, efficient exact attention, linear attention and recurrent/state-space updates. Give one running-sum state calculation and the retrieval/precision limits it cannot remove. Figure: the same request traced along each resource axis, with concrete counts. Exercises classify cards and reject comparisons that equate active with resident memory. Sources: Shazeer MQA, GQA, Switch, sparse-attention, linear-attention and Mamba papers. Keep kernels for Chapter 31 and implementations at map depth. Handoff: training must place weights, states and activations somewhere.

### Chapter 27 — Account for every stored category

Question: why does a model whose weights fit still fail to train? Derive bytes for an explicit mixed-precision Adam scenario: working weights, gradients, master weights, two accumulators, supplied saved activations, then separately add scratch/communication headroom. Units distinguish GB/GiB. Contrast MG-2's actual float64 choices. Explain microbatch accumulation with unequal valid-target counts, data/tensor/pipeline parallelism, optimizer-state sharding, activation recomputation and recovery. A small floating-point example motivates range and rounding risks without claiming all 16-bit types behave alike. Figure: which rank owns a tensor and where communication/restore is needed. Exercises recompute a shard budget, diagnose a biased accumulated gradient and incomplete recovery. Sources: mixed precision, ZeRO and Megatron papers; pinned PyTorch documentation. GPU experimentation is optional and unmeasured. Handoff: memory access also enables controlled internal interventions.

### Chapter 28 — Match the intervention to the causal claim

Question: if red is decodable, did that information make the answer red? Supply a complete two-coordinate causal teaching model with an unused yet perfectly decodable feature. Compute its logits before and after clean-to-corrupt patching, a matched inert-site control and reverse patching. Declare all prompts, sites and selection rules; no constructed result is labeled a trained Mini GPT finding. Explain probe/attribution, a logit lens's projection assumption, intervention specificity and a circuit as a tested subgraph hypothesis. Figure: observed channel versus used channel with the same decoder accuracy but different patch effects. Exercises distinguish necessity, sufficiency in a setting and distribution-shift confounds. Sources: probe control tasks, causal tracing/activation patching and circuit research. Core is fixed-result analysis; actual tiny arithmetic is CPU reproducible. Handoff: logits still need an explicit selection policy.

### Chapter 29 — Make the selection distribution inspectable

Question: how can the same scores produce different next tokens? Fixed candidate order and logits ln(4), ln(2), 0, 0 give exact masses 4:2:1:1. Derive greedy, temperature 2, top-k=2 and top-p at a boundary, including stable ties, renormalization and cumulative intervals. Temperature zero is a separately defined greedy convention. Work a two-step beam tree where local and sequence optima differ, including EOS and the impact of length normalization. A declared additive repetition penalty changes only selection scores. Deliver deterministic draw records plus actual MG-2 generation configurations on a structured suffix and a creative continuation task; judge their different criteria without inventing diversity or quality. Figure: scores → eligible mass → cumulative intervals → selected ID. Exercises include a tie, boundary draw and beam failure. Sources: sampling/beam/degeneration research and fixed-version generation documentation. Handoff: every appended token requires another model run.

### Chapter 30 — Separate prompt work, token work and stored history

Question: why does the first token arrive later than later tokens? Use supplied timestamps to calculate queue time, TTFT, inter-token gaps and mean TPOT with denominators explained. Trace a two-layer cache growing by one position: K and V per layer/head/coordinate, not final answers. Derive 2LTH_kv d b bytes per sequence and state concurrency/precision assumptions. Quantize four declared values with an explicit scale, integer range, tie and clipping rule; show a near-tied output that can flip. Figure: prompt prefill, first selection, subsequent decode, cache growth and stop. Exercises vary GQA/concurrency and distinguish missing output from zero latency. Sources: decoder caching documentation and original quantization papers. No cache optimization is claimed for the existing full-prefix Mini GPT implementation. Handoff: simultaneous requests change the objective.

### Chapter 31 — Measure the service, not just one operation

Question: how should the same arrivals and lengths be served? Fixed workload, two supplied schedules, all emission times and a single declared observation window. Compute per-request TTFT/TPOT, aggregate output throughput and assumed resource-time cost. Explain prefix identity/isolation, exact tiled attention, target-verified speculative proposals (including rejection correction), and continuous admission between decode steps. Explicitly locate model, engine, server and application. Figure: a request timeline showing reduced idle slots and an exposed queue tradeoff. Exercises examine median versus tail, a wrong speculation acceptance rule and unsafe cache reuse. Sources: FlashAttention, speculative decoding, Orca and vLLM/PagedAttention papers plus versioned maintainer docs. Supplied traces are scenarios, not measured speedups. Handoff: performance cannot decide what counts as an acceptable answer.

### Chapter 32 — Freeze the decision before observing candidates

Question: what would count as a successful fictional travel assistant? Inherit all nine KA-0 query IDs and relevance labels and its five documents; preserve retrieval as a separate stratum. Add a versioned, compact bilingual answer diagnostic with explicit updated/historical limits, abstention, language and action-boundary cases. Fix rubric, hard gates, split roles, candidate identities, repeats and failure taxonomy before running. Public diagnostic examples are not secret held-out product tests. A substring matcher passes a negated answer and fails an equivalent phrase; a static adjudication exercise motivates evidence-aware review. Show numerator/denominator, paired outcomes and repeat-level versus case-level uncertainty. The completed chapter uses an exact small probability illustration rather than presenting a population confidence interval for deliberately selected public cases. Figure: contract → frozen inputs → repeated records → adjudication → decision. No uncalibrated LLM judge or invented human panel. Handoff: apply exactly this contract in Chapter 33.

### Chapter 33 — A verifiable decision can reject both candidates

Question: should either available local snapshot be selected? Compare the existing MG-2 step-50 and step-600 snapshots with unchanged architecture/tokenizer and identical prompts, language strata, seed matrix and budgets. Keep all Keyword/Count/TF-IDF same-set retrieval baselines. Record raw bytes, stop/failure reasons, every completion, measured CPU timing, identities, environment and repeated outcomes. A vendor-neutral stable report weighs capability, language, latency, cost assumptions, local data flow, license, availability and maintenance. It must reject both if hard gates fail; this still completes a model/configuration selection report. A dated online appendix verifies actual local software/model artifacts and a clearly unmeasured external API/open-weight candidate's official model/license/pricing information, without turning the method into a shopping list. Distinguish open weights from the Open Source AI Definition and API price from measured workload cost. Exercises make a paired decision and identify missing evidence. The Part V checkpoint connects data → training → selection → running → serving → evaluation; Chapter 34 asks why a base model needs instruction training.
